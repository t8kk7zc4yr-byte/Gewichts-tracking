# Gewichts-Tracker

Web-App zum täglichen Erfassen des Körpergewichts: Tagesliste mit Veränderung zum Vortag, Verlaufsdiagramm, Wochendurchschnitte (Sonntag bis Samstag), Phasen (Diät, Aufbau, Erhalt), Zielgewicht und Notizen.

* Läuft vollständig im Browser und nach dem ersten Öffnen auch offline.
* Die Daten liegen ausschließlich auf dem jeweiligen Gerät. Dieses Repository enthält keine persönlichen Daten.
* Installation auf dem iPhone: Adresse in Safari öffnen, Teilen, "Zum Home-Bildschirm".

Excel-Unterstützung: SheetJS Community Edition 0.18.5 (Apache-2.0), siehe `xlsx.LICENSE`.
